# Ephemera — AI Trip Journals & Itineraries

Ephemera is an AI-powered travel planner styled like an analog traveler's journal. Users describe a destination, duration, and party size, pick a fare tier (Budget / Mid / Premium / Custom), and receive a day-by-day itinerary generated by Google's Gemini model — complete with attractions, cultural sites, local events, and fun activities.

## File-by-File Reference

### Entry points & config

- **`vite.config.ts`** — Extends `@lovable.dev/vite-tanstack-config` (bundles TanStack Start, Tailwind v4, React, Nitro/Cloudflare). Redirects Nitro's built server entry to `src/server.ts`.
- **`tsconfig.json`** — Strict TS, bundler resolution, `@/*` path alias → `src/*`.
- **`components.json`** — shadcn/ui generator config (aliases, style, base color).
- **`package.json`** — Scripts: `dev`, `build`, `build:dev`, `preview`, `lint`, `format`.

### Server / SSR

- **`src/server.ts`** — Cloudflare Worker `fetch` handler. Wraps TanStack Start's SSR entry, normalizes h3-swallowed 500s, and renders a static error page on catastrophic failure.
- **`src/start.ts`** — Registers a server request middleware that catches thrown errors during request handling and returns the fallback error HTML.
- **`src/lib/error-capture.ts`** — Buffers the last uncaught SSR error so `server.ts` can surface it in logs.
- **`src/lib/error-page.ts`** — Returns a self-contained HTML string for the 500 fallback page.
- **`src/lib/lovable-error-reporting.ts`** — Ships client errors from React error boundaries back to the Lovable devtools channel.

### Routing shell

- **`src/router.tsx`** — Factory `getRouter()` that creates a per-request `QueryClient`, wires it into `createRouter`'s context, enables scroll restoration, and sets `defaultPreloadStaleTime: 0`.
- **`src/routeTree.gen.ts`** — Auto-generated route tree from files in `src/routes/`. Never edit by hand.
- **`src/routes/__root.tsx`** — The app shell. Defines `<html>/<head>/<body>`, global `<head>` metadata (title, description, OG/Twitter tags), Playfair Display + Inter + JetBrains Mono font links, the shared `SiteHeader`, the `<Outlet />`, the sonner `<Toaster />`, and the root `NotFoundComponent` / `ErrorComponent` boundaries.

### Pages (routes)

- **`src/routes/index.tsx`** — Landing / Explore page. Hero, live itinerary preview, Features grid, "How it works" step-by-step, traveler Stories, and tier ticket-stub cards linking to `/planner`.
- **`src/routes/planner.tsx`** — Trip Planner form (destination, duration, travelers, prompt, tier selector). Calls the `generateItinerary` server function through TanStack Query and renders the AI-generated day-by-day journal.
- **`src/routes/profile.tsx`** — Signed-in user profile: traveler stats and a "Saved journals" archive.
- **`src/routes/settings.tsx`** — Preference controls: dark mode toggle, email updates, default fare class.
- **`src/routes/auth.tsx`** — Combined sign in / sign up form with client-side validation, backed by `src/lib/auth.ts`.
- **`src/routes/README.md`** — Reference for TanStack Start's file-based routing conventions.

### Components

- **`src/components/site-header.tsx`** — Full-width sticky navigation with brand mark, primary links (Explore / Planner / My Logs), a Settings shortcut, and a session-aware account dropdown (profile, settings, sign out) or a Sign in CTA.
- **`src/components/ui/*`** — shadcn/ui primitives (Button, Input, Card, Dialog, DropdownMenu, Switch, Sonner, etc.) — themed via CSS tokens in `styles.css`.

### Hooks

- **`src/hooks/use-mobile.tsx`** — `useIsMobile()` hook that tracks whether the viewport is below the mobile breakpoint.

### Library modules

- **`src/lib/auth.ts`** — Prototype auth. Exposes `getSession`, `setSession`, and the `useSession()` hook that reads/writes a `SessionUser` from `localStorage`, plus `signIn` / `signOut` helpers and a cross-tab `storage`-event listener.
- **`src/lib/itinerary.functions.ts`** — The AI server function `generateItinerary`. Validates input with Zod, constructs the system + user prompt (fare-tier briefs, JSON schema instructions), calls the Gemini `generateContent` REST endpoint, and returns a typed `Itinerary` (`days[]`, `activities[]`, `tips[]`). Reads `VITE_GEMINI_API_KEY` inside the handler.
- **`src/lib/utils.ts`** — `cn()` helper (`clsx` + `tailwind-merge`) for conditional class composition.

### Styles

- **`src/styles.css`** — Tailwind v4 entry. Declares `@theme` tokens (colors in `oklch`, font families, radii), custom utilities like `ticket-cutout` for the journal/ticket-stub aesthetic, and base element styles.

## Feature Map

| Requirement                                                      | Where                                                                             |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| AI itinerary from a natural-language prompt                      | `src/lib/itinerary.functions.ts` → `src/routes/planner.tsx`                       |
| Day-by-day plan with attractions / events / culture / activities | `Itinerary` schema in `itinerary.functions.ts`                                    |
| Fare tiers (Budget / Mid / Premium / Custom)                     | `TierEnum` in `itinerary.functions.ts`, tier cards in `index.tsx` & `planner.tsx` |
| Landing page (features, how-to, stories)                         | `src/routes/index.tsx`                                                            |
| Trip Planner page                                                | `src/routes/planner.tsx`                                                          |
| Profile page                                                     | `src/routes/profile.tsx`                                                          |
| Settings page                                                    | `src/routes/settings.tsx`                                                         |
| Sign in / sign up                                                | `src/routes/auth.tsx` + `src/lib/auth.ts`                                         |
| Profile & settings reachable from the header                     | `src/components/site-header.tsx`                                                  |

## Local Development

```bash
bun install
bun run dev        # start Vite dev server
bun run build      # production build (Cloudflare Worker output)
bun run lint       # eslint
bun run format     # prettier
```

Set `VITE_GEMINI_API_KEY` in `.env` to enable itinerary generation.
